# Haolin Luo’s Baptism

A responsive, static invitation and service program for Haolin Luo’s baptism on July 26, 2026 at 5:00 PM.

## Preview locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The song buttons link to official sheet music hosted by The Church of Jesus Christ of Latter-day Saints.
